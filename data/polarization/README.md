# Static pulsed polarization data

The **Pulsed polarization** GUI creates a timestamped session folder here.
Each contains eight Alice/Bob setting folders with raw T3 and metadata, a
`session.json` manifest, and timestamped `analysis` folders with PNG/CSV/NPZ
outputs. Keep each raw file with its metadata and session manifest.

Instructions: [Pulsed polarization](../../pulsed_GUI/PULSED_POLARIZATION.md).
