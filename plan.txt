CONFIRMED BENCH
- NI USB-6351: AO0 Alice; AO1 Bob; Ctr0/PFI12 -> BDL SYNC IN.
  BDL TRG OUT -> PicoHarp SYNC; PBS detector outputs -> CH1/CH2.
  Existing NI detector input wiring remains reserved; do not casually reassign it.
- External triggering tested from 1 kHz to 1 MHz. Above 1 MHz the user manually
  disconnects PFI12 and selects internal 2, 20 or 80 MHz (or CW).
- Reported -150 to +150 V transition settles smoothly in slightly under 1 us.
  Good scope profiles: 500 kHz / 1200 ns delay; requested 750 kHz / 900 ns
  (integer clock realizes ~751,880 Hz). Delay is AO sample clock -> PFI12.
  One pulse per voltage works; Alice/Bob switching is synchronized.
  TTL OUT and TRG OUT reportedly align within ~1 ns. Preserve scope captures.
- QKD arrival measurements require CH2 +4.5 ns input offset, applied once.
  Historical SYNC threshold was -250 mV; latest saved polarization profile uses
  -60 mV falling, CH1 +200 mV rising, CH2 +200 mV rising, offsets 0/0/+4.5 ns.
  User correction: both detector inputs use rising edges; only SYNC uses falling.
  Profiles are editable; confirm actual working settings rather than universalizing
  these values. Different saved tools may have different input settings.
- QKD setup handles arrival/gate calibration and polarization/protocol data.
  Separate quantum emitter setup handles paper-quality lifetime/g2, outside
  this repository. The QKD PBS is not swapped for an HBT beamsplitter.

  Match notebook N to the GUI value; range/order and CSV columns are unchanged.
  Data: data/eoms; guide: pulsed_GUI/EOM_CALIBRATION_SWEEP.md.
  Sweep addition verified with 114 passing offline tests; hardware test pending.

  settings retained per mode. Older duplicated pulsed code archived, data retained.
- Live alignment: PicoHarp rates with live NI clock and Alice/Bob voltage changes.
- Polarization matrix: eight static settings, both detectors, sixteen arrival
  histograms and count/probability matrices. User reports acquisition works.
  Default 60 s per setting; saved durations retained. Gate/rebin offline.
  Explicit internal 2/20/80 MHz selector with manual changeover confirmation.
- Repeating H-V-R-L: Alice cycles four states, Bob switches basis every four
  trials, giving all eight combinations. Finite hardware-timed AO + delayed clock.
- Random BB84: independent OS-random Alice state and Bob basis per trial.
  Complete choices and voltage waveforms saved before output; no regeneration.
  Both modes save ungated T3 and warm-up data, with bounded buffer streaming.
  Start with 1 s warm-up + 1 s experimental output at 500 kHz / 1200 ns.
- Calibration workflow retained: EOM_V_sweep.py -> calibration notebook.

  Guides: README.md, pulsed_GUI/BB84.md, pulsed_GUI/PULSED_POLARIZATION.md.

NEXT BENCH STEPS — ONE AT A TIME
1. Static matrix: collect sufficient counts (60–300 s per setting as appropriate),
   optionally internal high-rate troubleshooting. Confirm voltage labels, detector
   outcomes, arrival offsets and a provisional gate. Keep raw T3 ungated.
2. Short ordered run: scope-check first AO/trigger, warm-up transition and final
   delayed pulse. Then test longer output across multiple USB buffer refills.
   Verify generated counts, PicoHarp flags and cleanup in session.json.
3. Establish and test NI sample zero relative to PicoHarp SYNC index, e.g. using
   a hardware marker with verified boundary convention. Adapter/wiring remains
   unresolved. No marker control is implemented yet. First detection, software
   timestamps and discarding warm-up do NOT establish the origin. A quiet-laser
   start is not required; user rejected that architecture.
4. Verify switched optical fidelity against a static baseline at the same source
   conditions; compare 500 kHz and ~750 kHz. Check worst-case transitions.
5. After origin and fidelity validation, accept random data for downstream
   sifting/reconciliation/privacy amplification; then loss/gate/stability sweeps
   with repeat acquisitions and source characterization from the emitter setup.
