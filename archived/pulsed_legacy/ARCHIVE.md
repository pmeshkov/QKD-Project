# Archived standalone pulsed tools

These are the original `pulsed/` code, profiles, tests and guides, archived during repository consolidation. The active implementation is [`pulsed_GUI/`](../../pulsed_GUI/), launched through [`launch.py`](../../launch.py) at the repository root.

The files here are preserved unchanged for historical reference. Their old README describes earlier wiring limitations and is not the current operating guide. Running these scripts from this archive would also change their default relative output directories; use the active GUI instead.

**Original measurements remain in [`pulsed/runs/`](../../pulsed/runs/).** No raw data or metadata moved with these scripts.

Archived files: `laser_clock.py`, `laser_clock_gemini.py`, `ph330.py`, `ph330_acquire.py`, `ph330_lifetime.py`, `ph330_preview.py`, the two PH330 JSON profiles, four `test_*.py` files, and the original README/PH330/lifetime guides.
